# GPU Indicator

Маленькая утилита для Windows 10/11: показывает в трее, сколько видеопамяти (VRAM) занято на видеокарте NVIDIA.

- Один exe (~250 КБ), без установки и без зависимостей.
- Цвет иконки зависит от заполнения: зелёный до 70%, жёлтый до 90%, красный выше.
- В подсказке при наведении: модель GPU, занято / всего и свободно.
- Меню по правому (или левому) клику:
  - **Видеокарта** — выбор GPU, если их несколько;
  - **Показывать на иконке** — процент или занятые гигабайты;
  - **Частота обновления** — 1, 2, 5 или 10 секунд;
  - **Запускать вместе с Windows**;
  - **Выход**.

Данные берутся из NVML (`nvml.dll`), которая ставится вместе с драйвером NVIDIA. Это тот же источник, что у `nvidia-smi`.

## Установка

Скачайте `GpuIndicator.exe` со страницы Releases (или из артефактов последней сборки в Actions) и запустите.

Windows по умолчанию прячет новые иконки в область скрытых значков. Чтобы индикатор был виден всегда, перетащите его из-под стрелки `^` на панель задач.

Настройки хранятся в `HKCU\Software\GpuIndicator`, автозапуск — в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Права администратора не нужны.

## Сборка

Нужны CMake 3.20+ и один из компиляторов.

**Visual Studio 2019/2022** (в «Developer PowerShell»):

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
# build\Release\GpuIndicator.exe
```

**MinGW-w64 на Linux** (кросс-компиляция):

```sh
sudo apt install g++-mingw-w64-x86-64-posix cmake
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake
cmake --build build
# build/GpuIndicator.exe
```

Сборка при каждом пуше идёт в GitHub Actions. Тег вида `v1.0.0` создаёт релиз с exe.

## Устройство

| Файл | Что делает |
|---|---|
| `src/main.cpp` | Скрытое окно, иконка в трее, таймер опроса, меню |
| `src/nvml.cpp` | Динамическая загрузка `nvml.dll` и чтение памяти GPU |
| `src/icon.cpp` | Отрисовка иконки с числом (GDI + альфа-канал) |
| `src/settings.cpp` | Настройки и автозапуск в реестре |
| `res/` | Манифест (DPI, Common Controls), иконка приложения, версия |
| `tools/make_icon.py` | Генератор `res/app.ico` |

## Особенности

- **Занятая память** — значение `used` из `nvmlDeviceGetMemoryInfo`, как в `nvidia-smi`. Оно может немного отличаться от «Выделенной памяти» в Диспетчере задач.
- **Ноутбуки с Optimus**: опрос NVML может не давать дискретной видеокарте засыпать. Если это заметно по батарее, поставьте интервал побольше.
- Без драйвера NVIDIA иконка серая со знаком «?», а программа раз в интервал пробует подключиться снова.
